## 2024-07-27 - Command Injection in Tool Execution via execAsync
**Vulnerability:** The codebase executed tools like `grep`, `find`, and `ast-grep` by concatenating user-provided variables (`pattern`, `globPattern`, `rule`) into a single command string executed via `child_process.exec`. An attacker could exploit this by providing shell metacharacters in these variables, leading to arbitrary command execution on the host system.
**Learning:** Shell evaluation through functions like `exec` (or `promisify(exec)`) handles parsing and executes shell specifics. Naive string sanitization via `.replace(/'/g, "'\\''")` is often insufficient and error-prone, especially when combining many variables or dealing with edge cases in Bash globbing.
**Prevention:** Always use `execFile` (or `execFileAsync`) passing the executable as the first argument and an array of individual argument strings. This bypasses the shell interpreter entirely, ensuring variables are evaluated strictly as strings passed to the process.
